Controls

Control What it does
Colori (colours) The gradient’s colours, from shadows to highlights.
Livelli (levels) 0 = continuous gradient; a number = hard colour bands.

Common adjustments

Every style starts from the Regolazioni (adjustments): Luminosità (brightness) and Contrasto (contrast) change the greyscale before the style reads it, Inverti toni (invert tones) swaps lights and darks.

Tip

With few levels you get a screen-print look.
