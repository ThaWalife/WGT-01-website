## How to use a style

1. Select the image layer (and a selection, if you like).
2. Choose the style and a preset.
3. Fine-tune the controls while watching the **Anteprima live** (live preview).
4. Confirm: the result is a Smart Object you can reopen with **Modifica** (edit).

## Common adjustments

Every style starts from the **Regolazioni** (adjustments): **Luminosità** (brightness) and **Contrasto** (contrast) change the greyscale before the style reads it, **Inverti toni** (invert tones) swaps lights and darks.

## On several layers

With **Tutti i livelli** (all layers) the style is applied to every visible image layer (including inside groups), and each layer becomes its own Smart Object. {{name}} results, text and hidden layers are skipped.
