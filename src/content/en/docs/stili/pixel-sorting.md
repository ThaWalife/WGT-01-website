## Controls

| Control | What it does |
|---|---|
| **Soglia bassa** (low threshold) | Below this brightness pixels stay put. |
| **Soglia alta** (high threshold) | Above this brightness pixels stay put. |
| **Lunghezza massima** (maximum length) | Maximum length of each streak (0 = free). |
| **Interruzioni casuali** (random breaks) | Breaks the streaks at random points. |
| **Variante** (variant) | Changes the random breaks. |

## Common adjustments

Every style starts from the **Regolazioni** (adjustments): **Luminosità** (brightness) and **Contrasto** (contrast) change the greyscale before the style reads it, **Inverti toni** (invert tones) swaps lights and darks.

## Tip

“Inverti toni” reverses the sort direction. The adjustments matter here too.
