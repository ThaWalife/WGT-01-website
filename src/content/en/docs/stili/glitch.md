## Controls

| Control | What it does |
|---|---|
| **Dimensione blocchi** (block size) | Height of the shifted blocks. |
| **Quantità di glitch** (glitch amount) | How many blocks are hit. |
| **Strappo orizzontale** (horizontal tear) | How far the blocks shift. |
| **Pixelatura** (pixelation) | How coarse the blocks get. |
| **Sfasamento RGB** (RGB shift) | Distance between the red, green and blue channels. |
| **Livelli per canale** (levels per channel) | Reduces the colours of each channel. |
| **Variante** (variant) | Reshuffles the blocks at random: same settings, different pattern. |

## Common adjustments

Every style starts from the **Regolazioni** (adjustments): **Luminosità** (brightness) and **Contrasto** (contrast) change the greyscale before the style reads it, **Inverti toni** (invert tones) swaps lights and darks.

## Tip

The adjustments decide where the glitch goes: dark areas (or light ones with “Inverti toni”). Brightness at minimum = everywhere.
