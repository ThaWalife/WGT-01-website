> Exports to **SVG**. See [SVG export](/doc/esporta-svg/).

## Controls

| Control | What it does |
|---|---|
| **Distanza tra le linee** (line spacing) | Step between one line and the next. |
| **Angolo** (angle) | Tilt of the lines. |
| **Ondulazione** (waviness) | How much the lines wave. |
| **Lunghezza d’onda** (wavelength) | Width of each wave. |
| **Inizio del tratteggio** (hatching start) | The tone at which cross-hatching appears. |
| **Tratteggio incrociato nelle ombre** (cross-hatching in shadows) | A second set of lines in the darkest areas. |

## Common adjustments

Every style starts from the **Regolazioni** (adjustments): **Luminosità** (brightness) and **Contrasto** (contrast) change the greyscale before the style reads it, **Inverti toni** (invert tones) swaps lights and darks.

## Tip

The lines come out in SVG as filled paths: you can print them very large.
