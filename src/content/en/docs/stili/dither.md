## Controls

| Control | What it does |
|---|---|
| **Dimensione pixel** (pixel size) | Size of each dot. |
| **Intensità del dither** (dither strength) | How much each dot’s error spreads to its neighbours: low = flatter, high = more grain. |
| **Livelli** (levels) | How many tones remain (2 = just ink and paper). |

## Common adjustments

Every style starts from the **Regolazioni** (adjustments): **Luminosità** (brightness) and **Contrasto** (contrast) change the greyscale before the style reads it, **Inverti toni** (invert tones) swaps lights and darks.

## Tip

For a clean effect use few levels and a pixel size of 2–4.
