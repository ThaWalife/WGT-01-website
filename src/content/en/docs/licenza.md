## The donation

{{name}} is for everyone, with a minimum donation of **{{min_price}}**: you choose how much to give. Payment goes through **Payhip**, which accepts cards and PayPal and sends you the file straight away.

## The serial code

Along with the file you get a personal **serial code**. Upcoming versions of {{name}} will ask for it on first launch to unlock every feature.

- The code is yours: keep it with the Payhip email.
- If you ask for a refund, the code is deactivated.
- Lost your code? You’ll find it in the Payhip email or in your Payhip library.

> Downloads open with the first public release. Until then the [Download](/download/) page shows “Coming soon”.
