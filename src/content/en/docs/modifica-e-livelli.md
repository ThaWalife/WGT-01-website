## Edit

Every {{name}} result is a Smart Object containing a hidden copy of the starting image and the settings used. Select the result and press **Modifica** (edit): the panel reopens with those settings and you can change them.

> If you reopen a result made with an earlier version, it’s recalculated with the current algorithm: the look may change slightly.

## All layers

**Tutti i livelli** (all layers) applies the current settings to every visible image layer, including those inside visible groups. Each layer becomes its own Smart Object. {{name}} results, text layers and hidden layers are skipped.

## Undo

Every operation is a single step in Photoshop’s history: Ctrl/Cmd+Z undoes it entirely.
